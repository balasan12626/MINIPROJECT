# ML / AI Workflow

- Inspect only the ML/AI files relevant to the task.
- Do not inspect datasets or model weights unless necessary.
- Do not start training automatically.
- Reuse existing preprocessing, model, and evaluation logic.
- Preserve reproducibility and contract consistency between training and inference.
- Keep changes minimal and validated.
- Report results briefly.
