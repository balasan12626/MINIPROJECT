# Digital Twin Workflow

- Inspect only the relevant simulation or Digital Twin modules.
- Preserve the existing state/data flow.
- Reuse current interfaces and data models.
- Validate transformation and simulation behavior with focused checks.
- Avoid redesigning the full system for a local issue.
- Keep changes minimal and localized.
