# Database and API Workflow

- Inspect only the relevant data access, model, route, or service files.
- Preserve existing API contracts unless the task requires a change.
- Reuse current database utilities and patterns.
- Do not modify production data.
- Do not expose credentials.
- Validate focused database/API behavior with lightweight checks.
- Avoid unrelated schema or route changes.
