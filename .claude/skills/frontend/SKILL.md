# Frontend Workflow

- Inspect only the relevant React/Vite frontend files.
- Follow the existing component and routing structure.
- Reuse existing components and utilities.
- Keep styling and layout changes localized.
- Do not introduce new libraries unless explicitly requested.
- Preserve accessibility and responsive behavior where practical.
- Validate with the smallest relevant frontend check.
- Keep changes concise and minimal.
